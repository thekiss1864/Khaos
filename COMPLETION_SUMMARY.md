## 🎨 Customization Quick Start

### 1. Change App Name
```json
// package.json
"name": "your-app-name"

// src-tauri/tauri.conf.json
"productName": "Your App Name"
```

### 2. Modify Theme Colors
Edit `src/app.css` - search for `--color-primary`, etc.

### 3. Update App Icon
Replace icons in `src-tauri/icons/` directory

### 4. Change Window Size
Edit `src-tauri/tauri.conf.json` - look for `windows` section

## 🐛 Troubleshooting

### Common Issues

**App won't start?**
→ Check `QUICKSTART.md` → Troubleshooting

**Port 5173 in use?**
```bash
lsof -ti:5173 | xargs kill
```

**Dependencies error?**
```bash
rm -rf node_modules bun.lock
bun install
```

**Rust errors?**
```bash
cd src-tauri
cargo clean
cargo build
```

**Full Verification**
→ Follow `SETUP_VERIFICATION.md` checklist
